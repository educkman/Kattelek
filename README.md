# Kattelek 🐾

**Screen game for cats.** Critters scurry, freeze, dart, peek in from the edges and stalk across the screen to trigger your cat's hunting instinct. Tap a critter to "catch" it.

Runs in the browser — no install, no login, no tracking.

## Features

- 17 critters plus Mix: ball, disc, bee, mouse, bird, fish, fly, cockroach, Nokia-style snake, PC mouse, sasquatch, yeti, UFO, eyeball, ghost, jellyfish, tumbleweed
- Irregular prey-like movement: stop–start, sudden darts, shakes, stalking and peeking
- Colours chosen for cat vision (blues and yellows)
- Session timer that reminds you to finish with a real toy or treat
- Backgrounds: auto day/night, light blue, grey, night blue
- English, Norsk and Svenska
- Settings are saved on the device

## Play

Open the GitHub Pages link, lay the tablet flat on the floor and press **Start hunting**.

**iPad / iPhone:** open in Safari → Share → **Add to Home Screen** for true full screen.
Use **Guided Access** (Settings → Accessibility) to keep your cat from leaving the game.
Use Guided Access (Settings → Accessibility) to keep your cat from leaving the game.
Android tablet / phone: open in Chrome → ⋮ menu → Add to Home screen (or Install app) for true full screen.
Use App pinning (Settings → Security → App pinning) to keep your cat from leaving the game.
